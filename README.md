# 🎲 Casino Simulator

A Python casino simulator that stores player wallets between runs using text files.

## Features

- Tournament-style gameplay
- Mandatory tax that goes to the house
- Session counter
- Casino balance tracking
- File-based data storage

## Files

- `Casino.py` - Main game
- `Wallets.txt` - Stores player balances
- `Session_Counter.txt` - Tracks game sessions
- `Casino_Balance.txt` - Stores the casino's balance
